# Видео «Пробное ношение»

Запись реального HTML, переданного пользователем, в оформлении инструкции рассрочки.
Сам файл не изменён. Старые рассрочка, памятка, ZIP и видео не перезаписываются.

- Исходный автономный HTML: `dist/trial-wearing/Пробное ношение.html`.
- Готовое видео: `dist/trial-wearing/staff-walkthrough.mp4`.
- Сценарий: `record.cjs`; оболочка с курсором, подсказками и рамками: `shell.html`.
- Главы, контрольные кадры и результаты проверок: `chapters.json`.

В примере только вымышленные клиент, специалисты и паспортные данные.

## Повторить

Из корня репозитория, с установленными Playwright, системными Chromium и FFmpeg:

```sh
node training/trial-video/record.cjs --preview
TRIAL_VIDEO_WORK=/tmp/trial-video-new-take node training/trial-video/record.cjs
python training/trial-video/verify.py /tmp/trial-video-new-take
```

Для новой полной записи выбрать новую временную папку: общий модуль не перезаписывает
существующий MP4. Команда полной записи обновляет только видео пробного ношения и его манифест.

Показаны настройки города и года, многострочный список специалистов, сохранение и
проверка после перезагрузки, выбор специалиста, распознавание сообщения, автоматически
заполненные стоимость/залог и даты, ввод паспорта и контактов, одна итоговая проверка,
настоящее скачивание Word. Нативные окна Word не имитируются.

Видеозапись без звуковой дорожки. Подсказки отображаются рядом с текущей областью,
рамки следуют за DOM при прокрутке и приближении. Постоянных панелей с этапами нет.
Подсказки перед действиями держатся чуть дольше, а объяснение автоматических дат —
около шести секунд. Скорость ввода и движения камеры сохранена.

Общий способ записи описан в `docs/VIDEO-WITHOUT-DOWNLOADS.md`.
