# Договор рассрочки — один HTML со встроенным договором

**Откройте HTML двойным щелчком — договор и акт уже внутри.**
Ничего выбирать или запускать дополнительно не нужно. Приложение работает без сети и ИИ.

## Скачать

**[Скачать готовый комплект ZIP](https://github.com/dtarburihopps-ai/doc/raw/refs/heads/main/dist/contract-kit.zip)**

Распакуйте архив и откройте **«Договор рассрочки.html»** в Chrome или Edge.
Для работы нужен только этот HTML. Отдельный DOCX в комплекте — исходник для редких
изменений шаблона, он не требуется при обычном открытии приложения.

## Заполнение

1. Вставьте сообщение и нажмите **Распознать** либо заполните поля вручную.
2. Проверьте и при необходимости исправьте данные и текст в предпросмотре.
3. **Печать** открывает предпросмотр браузера; **Скачать DOCX** сохраняет заполненную
   копию в стандартную папку загрузок браузера.

Город и год меняются слева в **«Шаблон, город и год»**.

## Один раз обновить шаблон для следующих запусков

1. Измените исходный DOCX в Word и сохраните. Метки `{{ФИО}}`, `{{ТОВАР}}` и другие оставляйте.
2. В HTML раскройте **«Шаблон, город и год» → «Обновить шаблон Word»** и укажите этот DOCX.
3. Нажмите **«Сохранить HTML»** и дальше используйте скачанную обновлённую копию.

В неё уже встроен новый договор. Администраторам не нужно повторять эти действия
перед каждым клиентом. Настроенные город и год также сохраняются в этой копии.
Данные текущего клиента из полей и правки текущего предпросмотра в новый HTML не попадают.
Само сохранение отдельного Word не изменяет старый HTML: после правки шаблона нужен
этот разовый импорт и сохранение новой копии.

Подробная инструкция: **[Как пользоваться.txt](dist/Как%20пользоваться.txt)**.

## Проверки

Проверены пять сообщений, все поля, сроки 1–12, грамматика, округление, даты конца месяца,
правки предпросмотра, печать и DOCX. Проверены 216 сочетаний расчётов, а также обновление
Word и повторное открытие сохранённого HTML с новым шаблоном без сети и без данных клиента.
Проверки выполнены в Chromium/Linux. Установленный Microsoft Word/Windows и физический
принтер здесь недоступны; DOCX дополнительно открывался через LibreOffice.
