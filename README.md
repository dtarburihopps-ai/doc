# Договор рассрочки — автоматический Word-шаблон

Автономное заполнение договора и акта без интернета и ИИ.
**Выбирать папку или DOCX в странице больше не нужно.**

## Скачать и запустить

1. Скачайте **[готовый комплект ZIP](https://github.com/dtarburihopps-ai/doc/raw/refs/heads/main/dist/contract-kit.zip)**.
2. Полностью распакуйте архив в обычную папку.
3. Дважды щёлкните **«Запустить договор.cmd»**.

Откроется страница, которая сама загрузит Word из той же папки.
Окно запуска оставляйте открытым во время работы; после завершения закройте.
Windows может скрывать расширение `.cmd` и показывать только имя «Запустить договор».

Нужны Windows 10/11 и современный браузер. Используется встроенный Windows PowerShell:
ничего дополнительно устанавливать не требуется, права администратора не нужны.
HTML напрямую запускать не следует: браузер блокирует самостоятельное чтение соседнего Word.

## Работа

- Вставьте сообщение и нажмите **Распознать** либо заполните поля вручную.
- Данные сразу отображаются в редактируемом предпросмотре.
- Проверьте и при необходимости исправьте договор, акт и график.
- **Печать** открывает предпросмотр браузера; **Скачать DOCX** сохраняет заполненную копию
  в стандартную папку загрузок браузера. Исходник не перезаписывается.

## Изменение исходного договора

Откройте **«Шаблон рассрочки.docx»** в Word, измените город, год, реквизиты или постоянный
текст и сохраните. Приложение заметит изменение автоматически. Если в предпросмотре уже
есть ручные правки, оно предупредит перед заменой текста. Введённые поля сохраняются.
Год меняйте в дате договора и в дате акта.

Метки `{{ФИО}}`, `{{ТОВАР}}` и другие оставляйте: вместо них подставляются данные.
Используется «Шаблон рассрочки.docx», а при его отсутствии — единственный DOCX из папки.
При обновлении комплекта сохраните свой изменённый Word-шаблон.

Подробная инструкция: **[Как пользоваться.txt](dist/Как%20пользоваться.txt)**.

## Проверки

Проверены все поля и пять исходных сообщений, сроки 1–12, грамматика, расчёты, даты,
ручные правки, печать и DOCX; 216 сочетаний расчётов и 42 сценария в браузере.
Автозагрузка и обновление Word проверены с настоящим PowerShell-сценарием запуска,
извлечённым из поставляемого CMD, без диалогов выбора файла и без внешних запросов.
Проверки выполнены в Chromium и PowerShell 7/Linux; сам Windows PowerShell 5.1,
Microsoft Word в Windows и физический принтер в этой среде недоступны.
