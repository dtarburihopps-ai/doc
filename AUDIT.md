# Проверка договора рассрочки — 28.10.2026

Проверена текущая версия с кнопкой «Скачать и распечатать». Печать выполняется из Word.

## Результат

- Логика: 2494 проверок расчётов, дат, грамматики и распознавания, ошибок после исправлений нет.
- Интерфейс: 70 сценариев, все 19 элементов ввода проверены.
- Прогон интерфейса выполнен в оконном Chromium: клики, набор с клавиатуры,
  паузы при наборе, выделение, Enter, редактирование и скачивание. Скриншоты просмотрены.
- Word: 12 скачанных документов и 484 проверки содержимого и частей DOCX.
- Базовый тест скачивания и проверка экспортированного Word также пройдены.
- Шаблон Word, изображения, стили и колонтитулы не изменены.

## Найденные и исправленные ошибки

1. Без запятой после стоимости число месяцев/количество аппаратов могло подменять стоимость.
   Теперь берётся сумма после метки; в формуле с «=» — указанный конечный итог.
2. Округление иногда оставляло последний платёж нулевым. Исправлен выбор обычного платежа:
   сумма сходится, последний платёж положительный, когда остаток позволяет распределить его.
   Для слишком маленького остатка есть предупреждение, без запрета скачивания.
3. После пробела при правке в предпросмотре обновление DOM могло сбрасывать курсор и обрезать ввод.
4. Многострочное выделение в Chrome могло удалять связь адреса с полем формы. Добавлена защита
   редактируемого поля; внутренние переносы строк сохраняются.
5. Отложенное обновление могло прерывать набор при паузе. Перерисовка откладывается до выхода из поля.
6. Дата выдачи паспорта терялась, если была в строке «Кем выдан», а номер паспорта — отдельно.
7. Пустой взнос мог сопровождаться зелёным сообщением «Данные и суммы проверены».
8. Распознавание только ФИО могло незаметно переключить ручной взнос обратно на авто 50%.
9. Строка «Оплата картой» могла приниматься за ФИО.
10. Слитные инициалы «Н.Г.» могли попадать в поле имени. Теперь они остаются только в полном ФИО.

Подсказки также приведены к текущему процессу: скачивание Word вместо удалённой кнопки печати HTML.

## Автономность и настройки

Холодная загрузка HTML из памяти и скачивание DOCX проверены с отключённой сетью.
Внешних запросов нет. Проверены повреждённые настройки и запрет чтения/записи хранилища.
После перезагрузки сохраняются только город и год: ФИО и другие данные покупателя не сохраняются.

## Границы проверки

Среда проверки — Chromium/Linux. Прямое открытие file://, Windows, Microsoft Word
и физическая печать здесь недоступны. Содержимое скачанного DOCX проверено по XML,
целостности ZIP и сравнению частей с исходным шаблоном. Сам шаблон оставлен побайтово прежним,
для которого пользователь уже подтвердил правильную печать.
Парсер работает по правилам: новые свободные формулировки следует перепроверять в форме.
Формулы стоимости проверялись с явно указанным конечным результатом, как в исходных примерах.
